Apple Passwords. On a Mac signed into the same Apple ID, open the Passwords app and choose File → Export All Passwords to File. Import that CSV here, then delete the file. It is not encrypted. iPhone and iPad do not export this list — use the Mac.

Brave. Brave Sync cannot be read from another app. On a computer where Brave is signed in, open brave://settings/passwords, open the menu next to Saved passwords, and choose Export passwords. Import the CSV here, then delete it. Passwords you save in Brave later need another export.
