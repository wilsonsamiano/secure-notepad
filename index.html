🔑 Sync code

This code encrypts your notebook (AES-256-GCM). Sync turns on by itself after unlock. Your other devices use this same code. An invite code is different — it opens one pad only.

👤 Your name

Shown on your chat messages, calendar events and exports. You can change it anytime; messages and exports you already made keep the name they were made with.

🛰 Relays

Relays hold the encrypted notes, chat and calendar so a device that was offline still gets them. They cannot read anything. Run one on each Umbrel and add its Tailscale address here once — every device on this code picks it up.

⬇ Export

Download a readable copy to this device. Anyone on this sync code can export. Each export is recorded below for everyone on the code (it cannot see text copied by hand).

🤝 Shared pads

Invite someone to one pad, not the whole notebook. They never get your sync code, and they cannot open your other pads. Give them the invite from that pad’s ⋯ menu, or join one of theirs here.

💾 Backup

Export an encrypted backup file (needs your sync code to restore). Move it to another device any way you like — it is useless without the code.

ℹ About

Single-file app. Notes live encrypted in this device's storage (IndexedDB). Sync goes through your own relays and directly between devices; relays only hold ciphertext. Every device keeps a full encrypted copy. Conflicts: the newest edit wins. No account, no tracking.
